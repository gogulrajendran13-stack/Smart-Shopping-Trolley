

\# Smart Shopping Trolley



An ESP32-based Smart Shopping Trolley that automates product identification and billing using RFID technology, load-cell weight monitoring, LCD display, and Wi-Fi connectivity.



\## Project Overview



The Smart Shopping Trolley is designed to improve the shopping experience by allowing customers to scan products, monitor their cart total, and view shopping information through a web interface.



The system uses an ESP32 microcontroller as its central processing unit.



\## Features



\- RFID-based product identification using RC522.

\- Automatic cart total calculation.

\- Real-time weight readings using a load cell and HX711.

\- 16x2 LCD display for product and billing information.

\- Buzzer alerts for product scanning events.

\- Wi-Fi connectivity using ESP32.

\- Web-based shopping cart.

\- Razorpay test checkout interface.

\## How to Run



1\. Install Arduino IDE.

2\. Install the ESP32 board package.

3\. Install the required libraries.

4\. Copy secrets.example.h to secrets.h.

5\. Enter your own Wi-Fi configuration and test key.

6\. Open SmartShoppingTrolley.ino.

7\. Select the appropriate ESP32 board and COM port.

8\. Upload the program.

9\. Open Serial Monitor to view the ESP32 IP address.

10\. Connect to the same Wi-Fi network and open the ESP32 IP address in a browser.
